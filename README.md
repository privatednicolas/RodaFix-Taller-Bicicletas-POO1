# RodaFix - Sistema de Gestión para Taller de Bicicletas

Proyecto de idea inicial para la materia de Programación Orientada a Objetos I.

## Descripción
Programa de consola en Java que gestiona los clientes de un taller de bicicletas,
las bicicletas de cada cliente y las órdenes de reparación de cada bicicleta,
usando arreglos nativos de tamaño fijo.

## Estructura
- `src/Taller.java` — administra un arreglo de clientes (agregación)
- `src/Cliente.java` — administra un arreglo de bicicletas (composición)
- `src/Bicicleta.java` — administra un arreglo de órdenes (asociación)
- `src/OrdenReparacion.java` — entidad simple, sin arreglos
- `src/Main.java` — punto de entrada, prueba el límite de los arreglos
